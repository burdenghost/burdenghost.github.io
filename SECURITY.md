# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through the official BURDEN GHOST contact form:

https://burdenghost.com/#contact

Do not include passwords, authentication tokens, private keys, financial information, or unnecessary personal data in a report.

Please provide enough information to reproduce the issue safely, including the affected URL or component, the observed behavior, and a minimal proof of concept when appropriate.

## Scope

This policy covers the public BURDEN GHOST website and its static assets served from the official domain.

Third-party services linked from the site (including Formspree, Cloudflare Turnstile, Spotify, YouTube, and social platforms) are operated by their respective providers and should be reported through their own security channels when the issue is specific to those services.

## Security principles

The site is intended to use HTTPS, restrictive browser policies where supported, input validation, anti-spam controls, and minimal collection of contact-form data. Security changes should preserve the site's accessibility, discoverability, and core functionality.
